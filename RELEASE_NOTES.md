## UniLink Android v1.8.0

- Midnight is now a true AMOLED black theme.
- Accounts show initials avatars; Settings choices fill the row; Delete is red; the activity log is easier to read.
- Nothing is cut off behind the tab bar any more; the Connection tab uses a Wi-Fi icon.

### Update
Install `UniLink-v1.8.0.apk` over the previous version; accounts and settings are kept. The signing certificate SHA-256 is at the bottom of these notes (see SECURITY.md).
