## UniLink Android v1.3.0

### What's new
- **Battery tools.** The single "keep awake" lock is now two switches, **Keep CPU awake** and **Keep Wi-Fi at full power**, so you can try lighter settings. The Connection tab shows how many keepalives succeeded, failed, or ran late, so you can see whether a change hurt reliability.
- **Smaller and faster.** The APK is now a minified release build (R8), with unused resources and extra languages removed and baseline profiles for a quicker first launch.

### Reducing battery use
1. Leave both switches on for a day and note UniLink's share in phone Settings, Battery.
2. Turn **Keep Wi-Fi at full power** off for a day. Compare battery use, and check the Connection tab: failed or late keepalives mean it is too aggressive.
3. Only if that was still reliable, try turning **Keep CPU awake** off too.

### Install
Download `UniLink-v1.3.0.apk` below and install it over the previous version. Your accounts and settings are kept.

Verify the download with `UniLink-v1.3.0.apk.sha256` if you like. Signed with the project's debug key.
