## UniLink Android v1.11.0

- **Update notice.** Once a day UniLink asks GitHub for the latest release and, only if your version is older, shows a single quiet notification (once per version) that opens the release page. Nothing is installed automatically and no account data is sent. Switch it off in Settings > Tell me about new versions.
- Includes the data bars (Accounts and Connection tabs) from 1.10.x.

### Update
Install `UniLink-v1.11.0.apk` over the previous version; accounts and settings are kept. The signing certificate SHA-256 is at the bottom of these notes (see SECURITY.md).
