## UniLink Android v1.9.0

- **Check for update** button in Settings > About. Manual only: it asks GitHub for the latest release and opens the release page; nothing is installed automatically and no accounts or personal data are sent.
- Author name and a link to the GitHub project in the same panel.

### Update
Install `UniLink-v1.9.0.apk` over the previous version; accounts and settings are kept. The signing certificate SHA-256 is at the bottom of these notes (see SECURITY.md).

> Unofficial project, not affiliated with any university or with Sophos. Use only accounts you are allowed to use.
